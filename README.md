## Структура проекта

```
├── data/                     # JSON-конфигурация
│   ├── __init__.py           # DataStore (загрузка из JSON)
│   ├── services.json         # Услуги, комплексы, врачи, акции
│   ├── config.json           # Клиника, операторы, слоты времени
│   └── bookings.json         # Сохранённые записи (генерируется)
├── bot_logic_v2.py           # Логика бота (state machine)
├── bot_logic.py              # Устарела → импортирует v2
├── booking_store.py          # Хранилище записей с БД-логикой
├── web_server.py             # Flask веб-сервер (UI)
├── test_bot.py               # 45 unit-тестов
├── test_scenarios.py         # Старые сценарии
├── response_templates.py     # Шаблоны ответов
├── simulator.py              # Консольный симулятор
├── bot.log                   # Лог диалогов
└── README.md                 # Этот файл
```

## Быстрый старт

### 1. Веб-интерфейс
```bash
python3 web_server.py
# Откройте: http://localhost:5000
```

### 2. Консольный симулятор
```bash
python3 simulator.py
```

### 3. Тесты
```bash
python3 test_bot.py
```

### 4. Старые сценарии
```bash
python3 test_scenarios.py
```

## API веб-сервера

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/` | GET | Веб-интерфейс |
| `/api/init` | GET | Инициализация диалога |

| `/api/stats` | GET | Статистика записей |

## Расширение

### Добавить услугу
В `data/services.json` в массив `services`:
```json
{
    "id": "mrt_knee",
    "name": "МРТ коленного сустава",
    "type": "mrt",
    "price": 24000,
    "duration": "30 мин",
    "preparation": "Специальная подготовка не требуется",
    "keywords": ["колено", "коленный сустав"],
    "symptoms": ["болит колено", "колено опухло"]
}
```

### Добавить врача
В `data/services.json` в массив `doctors`:
```json
{"id": "doc_4", "name": "Имя Фамилия", "specialty": "Специальность", "experience": "10 лет", "image": "👨‍⚕️"}
```
