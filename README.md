# Медицинский бот - Симулятор диалогов

## Описание
Минимальная база для тестирования диалогов медицинского бота Nomad Clinic.

## Структура проекта

```
├── config.py           # Конфигурация (адрес, телефоны, график)
├── knowledge_base.py   # База знаний (услуги, цены, врачи, акции)
├── bot_logic.py        # Логика бота (обработка сообщений, скрипт записи)
├── simulator.py        # Консольный симулятор для тестирования
├── test_scenarios.py   # Автоматические тестовые сценарии
└── README.md           # Этот файл
```

## Быстрый старт

### Запуск симулятора
```bash
python3 simulator.py
```

### Запуск тестовых сценариев
```bash
python3 test_scenarios.py
```

## Возможности

### ✅ Реализовано
- Определение услуги по ключевым словам
- Автоматическое предложение комплексов со скидкой
- Сбор данных пациента (ФИО, возраст, телефон)
- Выбор даты и времени записи
- Подтверждение записи
- Передача оператору в сложных случаях
- Ответы на вопросы (адрес, график, акции, врачи)
- Медицинские ограничения (не ставит диагнозы)

### 📋 Скрипт записи
1. Пациент спрашивает про услугу
2. Бот называет цену и предлагает записаться
3. Сбор данных: имя → возраст → телефон → дата → время
4. Подтверждение записи

### 🚨 Передача оператору
Бот передаёт оператору при упоминании:
- Инсульт, онкология, рак, опухоль
- Конфликт, жалоба
- ОМС, страховка
- Консультация врача, лечение, диагноз, лекарства

## Примеры диалогов

### Пример 1: Запись на МРТ
```
👤 Сколько стоит МРТ поясницы?
🤖 МРТ поясничного отдела стоит 24 000 тенге. Когда Вам удобно пройти исследование?

👤 Завтра
🤖 Доступное время: 09:00, 10:00, 11:00... Какое время подходит?

👤 10:00
🤖 Подтвердите запись: [данные]
```

### Пример 2: Жалоба → Определение услуги
```
👤 Болит поясница и отдает в ногу
🤖 В таких случаях часто выполняют МРТ поясничного отдела. Могу помочь записаться.
```

### Пример 3: Предложение комплекса
```
👤 Хочу МРТ шеи
🤖 Также часто выполняют УЗИ сосудов шеи. Сейчас действует скидка на комплекс.
```

## Команды симулятора

| Команда | Описание |
|---------|----------|
| `/reset` | Начать новый диалог |
| `/stats` | Показать статистику |
| `/services` | Показать все услуги |
| `/help` | Помощь |
| `/exit` | Выход |

## Расширение

### Добавить услугу
В `knowledge_base.py` в словарь `SERVICES`:
```python
"мрт коленного сустава": {
    "name": "МРТ коленного сустава",
    "price": 24000,
    "duration": "30 мин",
    "preparation": "Специальная подготовка не требуется",
    "keywords": ["колено", "коленный сустав", "нога болит"]
},
```

### Добавить комплекс
В `knowledge_base.py` в список `COMPLEXES`:
```python
{
    "name": "Здоровые колени",
    "services": ["мрт коленного сустава", "узи коленного сустава"],
    "discount": "15%",
    "original_price": 34000,
    "discounted_price": 28900
}
```
