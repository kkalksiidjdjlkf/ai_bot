# 🏥 Nomad Clinic — Медицинский Бот

Python-бот для клиники Nomad Clinic с автоматической записью на МРТ/УЗИ, поддержкой транслитерации казахского языка и state machine архитектурой.

## ✨ Возможности

- **Автоматическая запись** — полный поток: выбор услуги → сбор данных пациента → подтверждение
- **State Machine** — структурированный диалог без if/elif дерева
- **Транслитерация** — автоматическое исправление казахского текста, набранного на русской раскладке
- **Распознавание симптомов** — рекомендация МРТ/УЗИ на основе жалоб пациента
- **Выбор врача** — определение врача по имени
- **Конфликты времени** — проверка занятых слотов
- **Rate Limiting** — защита от спама сообщениями
- **Мультисессийность** — независимые диалоги для каждого пациента (`session_id`)
- **Комплексы услуг** — предложение скидочных комплексов (МРТ + УЗИ)
- **Перевод оператору** — триггеры для сложных случаев (онкология и т.д.)
- **Персистентность** — записи сохраняются в JSON-файл
- **Статистика** — отчёт по записям, услугам, отменам
- **QR-код пациента** — текстовые данные для сканирования без интернета и авторизации
- **Автоочистка** — автоматическое удаление прошедших записей каждый час
- **🆕 Визуальный календарь** — интерактивный CLI календарь с просмотром бронирований
- **🆕 Google Calendar** — автоматическое создание событий при бронировании
- **🆕 Экспорт в .ics** — генерация файлов календаря для отправки пациентам

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Node.js зависимости (WhatsApp бот)
npm install

# Python зависимости (Terminal бот + Google Calendar)
pip install -r requirements.txt
```

### 2. Запуск всех ботов

```bash
npm start
```

Эта команда запускает:
- 📱 **WhatsApp бот** — подключается через QR код (Baileys)
- 💻 **Terminal бот** — доступен в этом же терминале

Оба бота используют **единое хранилище** `data/bookings.json` — записи видны в обоих.

### 3. Управление

В терминале Terminal бота доступны команды:
| Команда | Описание |
|---------|----------|
| `/reset` | Начать диалог заново |
| `/stats` | Показать статистику записей |
| `/calendar` | Показать предстоящие записи |
| `/export` | Экспортировать все записи в .ics |
| `/quit` | Выйти из бота |

Нажмите **Ctrl+C** для остановки всех ботов.

## 🧠 Архитектура

### State Machine

Бот проходит через состояния диалога:

```
greeting → collecting_name → collecting_age → collecting_phone
    → collecting_date → collecting_time → confirming → (reset)
```

Каждое состояние проверяет ввод и переходит к следующему.

### Классы

| Класс | Файл | Назначение |
|-------|------|------------|
| `MedicalBot` | `bot_logic_v2.py` | State machine диалога |
| `BookingStore` | `booking_store.py` | Хранилище записей (JSON) |
| `DataStore` | `data/__init__.py` | Загрузка и кэширование JSON |

### Потоки обработки сообщения

1. **Транслитерация** — исправление казахского текста (о→ә, у→ұ и т.д.)
2. **Rate limiting** — ограничение частоты запросов (10/60 сек)
3. **Завершение диалога** — обработка «спасибо», «стоп», «не надо»
4. **Перевод оператору** — триггерные слова (онкология, опухоль)
5. **Распознавание врача** — поиск по имени
6. **Распознавание симптомов** — рекомендация услуги по жалобе
7. **Распознавание услуги** — ключевые слова (МРТ, УЗИ, рентген)
8. **Поток записи** — сбор данных пациента
9. **Общие вопросы** — адрес, график, цены, врачи, акции

## 📊 Данные

# Nomad Clinic — WhatsApp Бот

Автоматический WhatsApp-бот для медицинской клиники **Nomad Clinic** (г. Астана).  
Поддерживает **русский и казахский** языки, записывает пациентов на МРТ/УЗИ/КТ и другие обследования, интегрируется с Google Sheets и Google Calendar.

---

## Возможности

- Двуязычный интерфейс: **русский** (`ru`) и **казахский** (`kz`), автоопределение по первому сообщению
- Переключение языка командами `/lang kz` / `/lang ru` или написав «қазақша» / «русский»
- Информация об услугах с ценами, длительностью и инструкцией по подготовке пациента
- Поиск услуг по части тела (шея, голова, колени и др.) — на обоих языках
- Полный флоу записи: имя → возраст → телефон → дата → время → подтверждение
- Проверка телефона (казахстанские номера +7/8 с операторами 701–779)
- Проверка даты — русские **и казахские** названия месяцев (январь … декабрь / қаңтар … желтоқсан)
- Информация об адресе, графике работы, специалистах клиники
- Комплексные программы (Здоровая спина, Здоровая шея) со скидками
- Интеграция с **Google Sheets** — запись появляется в таблице сразу после подтверждения
- Интеграция с **Google Calendar** — событие создаётся автоматически
- **Автоперезапуск** при разрыве соединения (exponential backoff, `scripts/run-forever.sh`)
- Общий файл `data/bookings.json` с Python-ботом

## Конфигурация `.env`

Создайте файл `nomad-whatsapp-bot/.env`:

```env
# ─── Google Sheets ────────────────────────────────────────────
GOOGLE_SHEETS_ENABLED=true
GOOGLE_SHEETS_ID=<ID вашей таблицы>
GOOGLE_SHEETS_SHEET_NAME=Bookings

# ─── Google Calendar ──────────────────────────────────────────
GOOGLE_CALENDAR_ENABLED=true
GOOGLE_CALENDAR_ID=primary

# ─── Google Service Account ───────────────────────────────────
# Поместите google-credentials.json в папку nomad-whatsapp-bot/
GOOGLE_APPLICATION_CREDENTIALS=./google-credentials.json

# ─── Ollama (опционально) ─────────────────────────────────────
OLLAMA_BASE_URL=http://localhost:11434
```

> **Без Ollama** бот работает полностью на встроенной логике (ключевые слова + шаблоны).  
> Ollama подключается только как fallback для нестандартных вопросов.

### Google-интеграция (если нужна)

2. Скачайте JSON-ключ, сохраните как `nomad-whatsapp-bot/google-credentials.json`
3. Выдайте Service Account доступ к таблице (Editor) и Calendar
4. Подробнее: `GOOGLE_CALENDAR_SETUP.md`, `GOOGLE_SHEETS_SETUP.md`

### Поток обработки сообщения

```
Входящее сообщение
    ↓
detectLanguage() → sessionLanguages (прилипает к сессии)
    ↓
Команды переключения (/lang kz, /lang ru, қазақша…)
    ↓
Глобальные слова (спасибо/рахмет → прощание, отмена/бас тарту → сброс)
    ↓
Активная запись? → handleBookingFlow() [7 шагов]
    ↓
isExplicitBookingRequest(да/иә) → startBooking()
    ↓
Ключевые слова (МРТ, УЗИ, адрес, график, врачи…)
    ↓
Поиск по части тела → findServiceByBodyPart()
    ↓
Ollama fallback (если OLLAMA_BASE_URL задан)
    ↓
Стандартный ответ
```

## Флоу записи

```
selecting_service → waiting_confirmation → collecting_name
    → collecting_age → collecting_phone → collecting_date
    → collecting_time → confirming → ЗАПИСЬ СОХРАНЕНА
```

При подтверждении запись одновременно сохраняется в:
- `data/bookings.json` (локально)
- Google Sheets (если `GOOGLE_SHEETS_ENABLED=true`)
- Google Calendar (если `GOOGLE_CALENDAR_ENABLED=true`)

## Troubleshooting

### Нет QR или бот не запускается
```bash
npm run build       # пересобрать dist/
npm run qr          # показывает только QR без полного старта
```

### Бот не отвечает на казахском
Напишите `/lang kz` или `қазақша` — принудительно переключит язык сессии.

### Google Sheets / Calendar не работает
1. Убедитесь, что `google-credentials.json` находится в папке бота
2. Service Account должен быть добавлен как **Editor** в таблицу
3. Смотрите логи: `GOOGLE_SHEETS ERROR` / `GOOGLE_CALENDAR ERROR`
4. При ошибках Google API бот продолжает работать — записи сохраняются локально

### Ошибка "Cannot find module"
```bash
npm run build   # пересобрать
```

### Сессия WhatsApp сбросилась
```bash
rm -rf auth_info/
npm start        # отсканируйте QR заново
```

### Ollama не запущен
Бот работает и без Ollama. Для включения AI-fallback:
```bash
ollama serve
ollama pull llama3.1:8b   # ~5 ГБ RAM
```
